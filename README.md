# Кости — счёт

Альфа-версия веб-приложения для подсчёта очков в играх с игральными костями. Статическое приложение без backend — работает в браузере на любом устройстве.

## Игры

- **Тысяча** — полностью реализована: ведение счёта, сбросы на круглых сотнях, бочка (880 очков), история ходов
- **Покер** — заглушка (в разработке)

## Возможности

- Настройка количества игроков (от 2 до 8) и их имён
- Поочерёдные ходы с добавлением очков или пропуском
- Автоматический учёт сбросов на 100, 200, …, 800
- Режим «бочки» при 880+ очках
- История последних 10 ходов
- Сохранение состояния в `localStorage` (прогресс не теряется при перезагрузке)
- Мобильный интерфейс, оптимизированный для iPhone

## Запуск локально

Клонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/aromana33/yatzy.git
cd yatzy
open index.html
```

Или запустите простой локальный сервер:

```bash
# Python 3
python3 -m http.server 8080

# Node.js (если установлен npx)
npx serve .
```

Затем откройте в браузере: `http://localhost:8080`

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub (например, `yatzy`)
2. Загрузите файлы проекта в корень репозитория (`index.html`, `styles.css`, `app.js`)
3. В настройках репозитория: **Settings → Pages**
4. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (или `master`) → папка **/ (root)**
5. Сохраните — через минуту сайт будет доступен по адресу:

   `https://aromana33.github.io/yatzy/`
